=== WHAT'S NEXT ===

The project has 4 separate features you can test:

1. ISL → Text (Gesture Recognition from Webcam)
   Command: python inference_classifier.py
   Time: ~2 minutes
   Requirements: Webcam

2. Text → ISL (Convert Text to Gestures)
   Command: python text_isl.py
   Time: ~5 minutes
   Requirements: ISL video files

3. Speech → ISL (Convert Speech to Gestures)
   Command: python sarvam_ai_speech.py
   Time: ~3 minutes
   Requirements: Microphone + Sarvam AI API

4. Medical Chatbot (Q&A with ISL Display)
   Command: cd med_chatbot && python main.py
   Time: ~10 minutes
   Requirements: PDF files + Groq API

=== RECOMMENDED TEST ORDER ===

Start with FEATURE 1 (easiest, just needs webcam):
   python inference_classifier.py

Then try FEATURE 3 (speech to gestures):
   python sarvam_ai_speech.py

Features 2 and 4 need additional setup/files.
