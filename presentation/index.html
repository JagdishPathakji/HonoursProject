Project Definition

The objective of this project is to develop an advanced, bidirectional Artificial Intelligence system that acts as a real-time translator between Spoken/Written English and Indian Sign Language (ISL).

The system aims to bridge the critical communication gap for the Deaf and Hard-of-Hearing community by providing modular tools that can synthesize 3D sign language animations from text and speech, while simultaneously recognizing physical hand gestures via live computer vision to translate them back into English text.

System Modules

The architecture is completely decoupled and split into five primary processing modules:

  1. Text-to-ISL Translation Module
  2. Real-time Speech-to-ISL Module
  3. Live ISL-to-Text Recognition Module
  4. Live ISL-to-Speech Translation Module
  5. Vector-based Medical RAG Chatbot

Module 1: Text-to-ISL Translation

Objective: Convert complex English text (like railway announcements) into continuous 3D skeleton animations for Indian Sign Language.

Deep Internal Architecture:

  • Input Ingestion: The system accepts raw English text strings from the user.
  • NLP Preprocessing (LangChain & Groq LLM): The text is fed into a highly optimized Prompt Template utilizing the gpt-oss-120b model via the Groq API. The LLM performs complex Natural Language Processing, specifically Lemmatization (converting words to their base root, e.g., "running" -> "run") and Part-of-Speech (POS) Tagging to strip unnecessary grammar and punctuation.
  • Lexical Tokenization: The output from the LLM is parsed into an array of strictly ISL-compliant root words.
  • Spatial Data Mapping: These tokens are mapped against coordinates.csv, a massive 95MB local database containing pre-recorded X, Y, Z spatial coordinates for thousands of signs.
  • 3D Skeleton Rendering: Using OpenCV (cv2) and NumPy, the system extracts the matched coordinates and mathematically draws connecting lines between the joints (Shoulders to Elbows, Wrists to Fingers) on a dynamic canvas, rendering a continuous 3D sign language animation.

Module 2: Real-time Speech-to-ISL

Objective: Capture live spoken audio and immediately play back high-definition ISL video translations.

Deep Internal Architecture:

  • Hardware Interfacing: The script utilizes the PyAudio library to interface directly with the system's microphone, capturing raw audio streams into memory buffers and encoding them as a .wav payload.
  • High-Fidelity Transcription: The audio payload is securely transmitted to the Sarvam AI API. Sarvam AI was explicitly integrated due to its unparalleled accuracy in parsing Indian-accented English and regional dialects, returning a highly accurate text transcription in milliseconds.
  • Dictionary Cross-Referencing: The transcribed text is validated against local_video_dictionary.py, a robust key-value store that acts as a router pointing to a repository of local high-definition .mp4 video files.
  • Seamless Video Stitching: The OpenCV VideoCapture engine initializes a sequence for each mapped word. It buffers the frames and plays them back sequentially, ensuring zero stutter and providing a fluid, life-like sign language video translation to the user.

Module 3: Live ISL-to-Text Recognition

Objective: Read live physical hand gestures from a Deaf user via webcam and translate them into English text in real-time.

Deep Internal Architecture:

  • Live Computer Vision: The webcam feed is captured and processed frame-by-frame using Google's MediaPipe Hands algorithm. This advanced Neural Network successfully isolates the hand from background noise and identifies 21 unique 3D spatial landmarks for each hand.
  • Mathematical Normalization: The X and Y coordinates are mathematically normalized relative to the bounding box of the user's hand. This geometric normalization ensures the prediction remains 100% accurate regardless of the user's distance or angle from the camera.
  • Feature Vectorization: The 21 spatial points are flattened into a dense 42-dimensional vector array.
  • Random Forest Classification: This dense vector is passed into a custom-trained Scikit-Learn Random Forest Classifier (stored locally as serialized Python .p pickle files). The Random Forest model traverses its decision trees to predict the exact gesture class.
  • Real-Time Graphical Overlay: The predicted English text is instantly drawn over the live video feed using cv2.putText, achieving real-time bidirectional translation.

Module 4: Live ISL-to-Speech Translation

Objective: Convert physical hand gestures into vocalized, spoken audio, allowing a deaf individual to "speak" aloud through the computer.

Deep Internal Architecture:

  • Live Inference Pipeline: This module utilizes the exact same Computer Vision and Random Forest Machine Learning pipeline as Module 3 to instantly predict the gesture class from the webcam feed.
  • Text-to-Speech (TTS) Routing: Once the English text string is predicted, it is immediately routed into a dedicated Text-to-Speech engine (e.g., pyttsx3).
  • Audio Synthesis: The TTS engine synthesizes the English text into human-sounding audio and plays it aloud through the system speakers, achieving true bidirectional vocal communication.

Module 5: Vector-based Medical RAG Chatbot

Objective: Provide an interactive, offline AI doctor that visually signs health diagnoses back to the user.

Deep Internal Architecture:

  • RAG Architecture: This module implements a cutting-edge Retrieval-Augmented Generation (RAG) pipeline designed using the LangChain framework.
  • Vector Database Storage: Massive medical PDF textbooks (dictionaries of diseases and symptoms) are mathematically chunked and converted into high-dimensional vector embeddings. These embeddings are securely indexed inside a Pinecone Vector Database.
  • Semantic Context Retrieval: When a deaf user asks a complex medical query, the system converts the query into a vector and performs a Cosine Similarity search within Pinecone to fetch the top-K most relevant medical text chunks.
  • LLM Context Injection: The retrieved medical facts are injected into a strict Prompt Template and sent to the Groq LLM. The LLM formulates a highly accurate medical diagnosis while simultaneously stripping out complex medical jargon and formatting the output specifically for Indian Sign Language structure.
  • GPU Rendering: The simplified, ISL-friendly diagnosis is finally passed back to the gpu_landmark_renderer.py script, which visually signs the medical advice back to the user in 3D space.

Technologies & Frameworks Used

  • Programming Language: Python 3.12
  • Large Language Models: Groq API (gpt-oss-120b), LangChain Framework
  • Computer Vision: OpenCV (cv2), Google MediaPipe (Hands & Pose detection)
  • Machine Learning: Scikit-Learn (Random Forest Classifiers), NumPy, Pandas
  • Vector Database: Pinecone (For Retrieval-Augmented Generation)
  • Audio Processing: PyAudio, Sarvam AI API (Speech-to-Text Transcription)
  • Frontend UI/UX: HTML5, CSS3, JavaScript (DOM Manipulation)
